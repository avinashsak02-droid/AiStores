# AI Store — Project Overview

## What is AI Store?

AI Store is a marketplace for AI tools and AI agents.

The goal is to create a platform where:

### Sellers
- Create an account
- List AI tools or AI agents
- Add descriptions and information about their AI products
- Sell their AI products

### Users
- Search for AI tools
- Discover AI tools
- View AI tool/product pages
- Use AI tools
- Buy AI tools

## Current development stage

AI Store is currently a prototype.

The project is being developed with heavy assistance from AI coding assistants.

The developer has basic coding knowledge, so code should be explained clearly when necessary.

## Development principles

1. Do not unnecessarily rewrite working code.
2. Before changing something, inspect the existing implementation.
3. Preserve existing functionality when adding new features.
4. Fix existing bugs before adding unrelated major features.
5. Do not assume that a feature works just because it was previously implemented.
6. When making changes, keep them as simple and reliable as possible.
